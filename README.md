# وَرْدِيّة | سجل الإنتاج

واجهة React وخادم Node محلي لإدارة إنتاج العمال. تُحفظ السجلات والمنتجات والملخصات في مشروع Supabase، بينما تبقى نسخة SQLite المحلية محفوظة كمصدر ترحيل احتياطي.

## التشغيل أثناء التطوير

```powershell
npm install
npm run dev
```

افتح <http://localhost:5173>. يشغّل الأمر واجهة Vite وواجهة API معًا. يتطلب المشروع Node.js 20.19+ أو 22.12+.

## إعداد Supabase Server

حزمة `@supabase/server` مضافة إلى backend. أكمل `SUPABASE_SECRET_KEY` في `.env` بالمفتاح الكامل من إعدادات API Keys في Supabase. ملف `.env` مستثنى من Git.

المتغيرات `SUPABASE_URL` و`SUPABASE_PUBLISHABLE_KEY` و`SUPABASE_JWKS_URL` تهيئ التحقق من JWT. المسار `GET /api/auth/me` يقبل رمز المستخدم في ترويسة `Authorization: Bearer <token>` ويتحقق منه ثم يعيد معرف المستخدم وبريده فقط. لا ترسل المفتاح السري إلى المتصفح.

قبل تشغيل الصفحة، نفّذ `supabase/schema.sql` مرة واحدة من Supabase Dashboard > SQL Editor. الجداول تستخدم RLS بلا صلاحيات للـanon أو المستخدمين؛ خادم Node وحده يصل إليها بمفتاحه السري. واجهات سجلات الإنتاج محلية على `127.0.0.1` حاليًا.

لترحيل بيانات SQLite الحالية، نفّذ المعاينة أولًا، ثم بعد إنشاء الجداول راجع العدد ونفّذ الرفع صراحة. لا تفتح التطبيق قبل الترحيل إذا كانت بيانات SQLite هي التي تريد الاحتفاظ بها على Supabase:

```powershell
npm run migrate:supabase
npm run migrate:supabase -- --apply
```

المعاينة لا ترفع شيئًا، والترحيل الفعلي يرفض الكتابة إذا كانت جداول Supabase تحتوي بيانات بالفعل. توجد حاليًا سجلات SQLite محلية؛ لا تُحذف عند الترحيل.

## الوظائف

- إنشاء السجلات وتعديلها ونسخها وحذفها، مع البحث والفرز وتقسيم الصفحات.
- اختيار المنتجات من قائمة دائمة وإضافة منتجات جديدة.
- استيراد Excel بصيغتي `.xlsx` و`.xls` وتصدير السجلات والملخص الشهري إلى CSV.
- حساب ملخص يومي وحفظه، ثم احتساب مكافآت الشهر حسب حصة كل عامل من الإنتاج.
- نقل بيانات `localStorage` القديمة تلقائيًا عندما تكون متاحة من عنوان التطبيق نفسه، أو اختيار **نقل نسخة قديمة** لاستيراد ملف JSON.

## نقل البيانات القديمة

إذا كانت بيانات النسخة القديمة في عنوان مختلف، افتح الصفحة القديمة من العنوان نفسه الذي استُخدم لحفظها، ثم نفّذ التالي في وحدة تحكم المتصفح. انسخ النص الناتج إلى ملف JSON، ثم اختر **نقل نسخة قديمة** داخل التطبيق الجديد:

```js
copy(JSON.stringify({
  workers: JSON.parse(localStorage.getItem("production_workers_v1") || "[]"),
  dailySummaries: JSON.parse(localStorage.getItem("daily_summaries_v1") || "[]")
}, null, 2));
```

الترحيل لا يستبدل قاعدة بيانات تحتوي على سجلات مسبقًا. يحتفظ التطبيق أيضًا بملفات HTML وJavaScript القديمة في جذر المشروع دون تعديل.

## البيانات والإنتاج

قاعدة البيانات: `data/production-worker.sqlite`. احتفظ بنسخة من هذا الملف للنسخ الاحتياطي.

```powershell
npm run build
npm start
```

بعد البناء، افتح <http://localhost:3001>. يستمع الخادم على الجهاز المحلي فقط.
