اختصارات لوحة المفاتيح

  • Enter — حفظ السجل الحالي
  • Ctrl + S — حفظ
  • Ctrl + N — إضافة سجل جديد
  • Ctrl + Shift + N — مسح النموذج (New)
  • Ctrl + Delete — حذف السجل المحدد
  • Ctrl + R — استعادة آخر حذف
  • Alt + ↑ / Alt + ↓ — السجل السابق / التالي
  • Home / End — أول / آخر سجل
  • Ctrl + F — بحث (Criteria)
  • F1 أو ? — إظهار/إخفاء هذه المساعدة
